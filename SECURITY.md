# Security policy

Report a suspected vulnerability in the Qualytics controller through [GitHub private vulnerability reporting](https://github.com/Qualytics/ingress-nginx/security/advisories/new). Include the controller image digest, the Kubernetes and Helm chart versions, and which configuration you believe is affected. Omit credentials and customer data.

Qualytics publishes security updates for its controller through the [fork's releases](https://github.com/Qualytics/ingress-nginx/releases). The Kubernetes project's historical releases and advisories are available in the [upstream archive](https://github.com/kubernetes/ingress-nginx).
